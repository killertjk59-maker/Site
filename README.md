# 🍽️ OSHONA — сайт, админ, Telegram-бот ва OSHONA AI (v2.0.0)

Сайти мизоҷ (`public/`), панели админ (`/admin`), Telegram-бот ва OSHONA AI — ҳама аз **як backend** ва **як нигоҳдории маълумот** (`data/*.json`) кор мекунанд.
Лоиҳа барои **Railway** омода аст (`railway.toml`).

> ⚠️ **Версияи 2.0.0 тағйироти амниятӣ дорад.** Пеш аз деплой «[Тағйироти муҳим](#-тағйироти-муҳим-нисбат-ба-v15)»-ро хонед.

## 🚀 Дар компютер (рушд)

```bash
cp .env.example .env        # ва дар .env ADMIN_PASSWORD-ро гузоред
npm install
npm start                   # http://localhost:3000
npm test                    # тестҳо
npm run check              # node --check ҳамаи файлҳо
```

Дар рушд (NODE_ENV бе production) агар `JWT_SECRET` ва `ADMIN_PASSWORD` набошанд, сервер калиди муваққатӣ ва пароли пешфарзии `admin123` истифода мекунад ва огоҳӣ чоп мекунад. **Дар production ин иҷозат нест.**

## 🌍 Деплой ба Railway (қадам ба қадам)

### 1. Репозиторий
Кодро ба GitHub бор кунед ва лоиҳаро дар Railway аз репозиторий **Deploy from Repo** кушоед (Nixpacks худаш `npm install` ва `npm start` мекунад). Версияи Node ≥ 20 (`engines`).

### 2. Variables (Railway → Service → Variables)

| Variable | Ҳатмӣ? | Тавсиф |
|---|---|---|
| `JWT_SECRET` | **ҳа** | камаш 32 аломати тасодуфӣ. Сохтан: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` |
| `ADMIN_USERNAME` | ихтиёрӣ | пешфарз `admin` |
| `ADMIN_PASSWORD` | **ҳа** | камаш 10 аломат; `admin123` ва ҳамонанд рад мешавад. Ё `ADMIN_PASSWORD_HASH` (bcrypt) |
| `DUSHANBE_CITY_WALLET`, `ALIF_WALLET` | ҳа | рақами ҳамёни шумо |
| `DUSHANBE_CITY_NAME`, `ALIF_NAME` | ихтиёрӣ | `OSHONA` |
| `DC_PAY_URL`, `ALIF_PAY_URL` | ихтиёрӣ | агар мерчант-линк дошта бошед (`{wallet}`, `{amount}`, `{code}`) |
| `CORS_ORIGINS` | ихтиёрӣ | origin-ҳои иҷозатдодашуда (вергул). Пешфарз — ҳеҷ (сайт аз ҳамон домен кор мекунад) |
| `CURRENCY` | ихтиёрӣ | `TJS` |
| `OPENROUTER_API_KEY` | барои AI | калиди OpenRouter (**ҳаргиз** дар код/GitHub нагузоред) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `TELEGRAM_WEBHOOK_SECRET`, `TELEGRAM_ADMIN_IDS` | барои Telegram | → «Telegram-бот» дар поён |

`PORT` ва `RAILWAY_*`-ро нависед — Railway худаш медиҳад. Ҳангоми RAILWAY_* ё `NODE_ENV=production` сервер режими production-ро истифода мебарад ва дар ҳолати заиф **оғоз намешавад** (огоҳии дақиқ дар лог).

### 3. Volume (МУҲИМ!)
Бе Volume маълумот бо ҳар деплой нест мешавад.
- Railway → Service → **Volumes** → **New Volume** → Mount Path: **`/app/data`**
- Redeploy. Меню аз `seed/` пур мешавад; фармоишҳо, бронкунӣ, промокодҳо ва расмҳо дар Volume мемонанд.

**Яке аз сервер нусха мегирад:** ҳар сабт `*.json.bak` (нусхаи пешина) нигоҳ медорад. Агар файли асосӣ вайрон шавад, сервер оғоз намешавад (маълумот беэътибор навишта намешавад) — файлро аз `.bak` бозгардонед.

> ℹ️ Нигоҳдории JSON барои **як нусхаи** сервер аст. Барои якчанд нусха ё ресторани калон ба PostgreSQL гузаред.

### 4. Домен
Settings → Networking → **Generate Domain**. Админ: `https://САЙТ/admin` (ё `/admin.html`).

## 🔐 Амният (хулосаи v2.0.0)

- **Фармоишҳо:** ҳар фармоиш токени дастрасии тасодуфӣ мегирад (ҳамчун хеш нигоҳ дошта мешавад). Мизоҷ бо сарлавҳаи `X-Order-Token` танҳо фармоиши худро мебинад (бе телефон/суроға). Админ бо JWT ҳамаро мебинад. Барои номаълум ва нодуруст ҳамеша 404.
- **ҷустуҷӯи фармоиш бо телефон ҳазф шуд** (он маълумоти мизоҷонро ошкор мекард). Фармоишҳои мизоҷ дар дастгоҳи худаш (localStorage) нигоҳ дошта мешаванд; аз дастгоҳи дигар Telegram-линк истифода мешавад.
- **Админ:** ҳамаи роҳҳо бо JWT (HS256, 12 соат). Вуруди бадро маҳдуд мекунад (10 кӯшиш / 15 дақиқа).
- **Санҷиши воридшаванда:** телефон, сана, вақт, миқдор, нарх, суроға, промо, таом — ҳудуд ва формат. HTML-и `< >` дар матни озод рад мешавад.
- **Расмҳо:** танҳо JPEG/PNG/WebP, бо сигнатураи файл (magic bytes), ҳадди 5 MB. HTML/SVG рад мешаванд.
- **Сарлавҳаҳо:** CSP (`script-src 'self'`), `nosniff`, `frame-ancestors 'none'`, `no-store` барои API.
- **CORS:** танҳо origin-ҳои `CORS_ORIGINS`.
- **Service worker (`oshona-v2`):** ҳеҷ гоҳ API-и хусусӣ, фармоиш, админ ё пардохтро кэш намекунад; кэши кӯҳна (v1) пок карда мешавад.
- **XSS:** ҳамаи маълумоти динамикӣ дар frontend escape мешавад; скрипти инлайн ва `onclick` нест.

## 💳 Пардохт (дастӣ, ба таври қаблӣ)

1. Мизоҷ фармоиш медиҳад → **онлайн** бо коди пардохт (`OSH-XXXXX`) ё **нақдӣ**.
2. Онлайн: равзанаи пардохт (ҳамён, сумма, QR) нишон дода мешавад → мизоҷ пул мефиристад → «Пардохт кардам ✓».
3. **Админ** ҳамён/ҳисобро дастӣ месанҷад ва **тасдиқ** ё **рад** мекунад (ҳамчун тугмаи «Пардохтро тасдиқ»/«Рад кардан»).
4. **AI ҳеҷ гоҳ пардохтро тасдиқ ё рад намекунад.**

Ҳолатҳо:
- Онлайн: `AWAITING_PAYMENT` → `PAYMENT_REVIEW` → `CONFIRMED` (PAID) → `COOKING` → `DELIVERING` → `DONE`; ё `PAYMENT_REJECTED`.
- Нақдӣ: `NEW` → `COOKING` → `DELIVERING` → `DONE` (ҳангоми DONE пул `CASH_COLLECTED` мешавад).
- Фармоиши онлайн то пас аз тасдиқ ба ошхона намеравад. Бекор кардани фармоиши пардохтшуда → `REFUND_DUE` (бояд баргардонда шавад).
- Амалҳои нодуруст 409 медиҳанд (масалан тасдиқи фармоиши нақдӣ, тасдиқи дуюбора).

**Ҳисоботи даромад** се чизро ҷудо нишон медиҳад: фармоишҳо, пардохтҳои тасдиқшуда (онлайн) ва пули воқеан гирифташуда (онлайн + нақд). Фармоишҳои бекоршуда ба даромад дохил намешаванд.

## 🥗 Меню, калория ва таркиб

- Ҳар таом: ном, расм, нарх, **вазни порсия**, **таркиб бо миқдор** (грамм), аллергенҳо, тегҳо, **манбаи маълумоти ғизоӣ** ва **дараҷаи эътимод** (`high/medium/low`).
- Калория, сафеда, равған ва карбо **дар backend** аз таркиб ҳисоб мешаванд: ҳар ингредиент × миқдор ÷ 100 аз `seed/ingredients.json`.
- Агар ингредиент дар маълумотнома набошад ё таркиб ворид нашуда бошад — рақам **ҳисоб намешавад** («маълумот нест»). Рақами сохта нест.
- `seed/ingredients.json` **маълумотномаи ориентировӣ** аст (умумӣ, НЕ рецепти OSHONA ва НЕ тасдиқшудаи лаборатория). Барои таомҳои шумо таркиби воқеӣ ва вазни порсияро дар админ ворид кунед.
- Меню-и `seed/foods.json` намунавӣ аст (`demo: true`). Онро дар админ тасдиқ ё нест кунед; панел огоҳӣ медиҳад.

## 🤖 OSHONA AI (OpenRouter)

- Калид танҳо `OPENROUTER_API_KEY` дар муҳити сервер аст. Ҳаргиз ба frontend, ҷавоб ё лог намеравад.
- Моделҳо дар `config/ai.json`: **асосӣ** `google/gemma-4-31b-it:free`; **захиравӣ** `nvidia/nemotron-3-super-120b-a12b:free`, `google/gemma-4-26b-a4b-it:free` (тафтиш: 2026-10-09, endpoint фаъол ва narx 0). Тафтиши дубора: `GET https://openrouter.ai/api/v1/models/{id}/endpoints`.
- Такрор бо backoff ва jitter на бештар аз 2 бор барои ҳар модел (429/5xx/timeout/холӣ); Retry-After то 5 сон; 401/402/403 бе такрор; 404/400 → модели навбатӣ.
- Пас аз ҳамаи моделҳо хато → тавсияи қоидавӣ бо паёми дӯстона (`source: "rules"`).
- Маҳдудият: `AI_DAILY_LIMIT` (пешфарз 500), 500 аломат барои савол, `max_tokens` 700, 12 000 аломат барои ҳамаи матн.
- Ба модел **ном, телефон, суроға** намефиристад; телефон/email дар савол маскарад мешаванд.
- Модел фақат ID-и таомҳои **дастнорас**-и менюро тавсия дода метавонад; рақами калорияи тасдиқнашуда пок карда мешавад.
- **Наврасон (<18) ва хостани лоғаршавӣ:** ҳадди калория, парҳез ва нақшаи лоғаршавӣ манъ аст.
- **Аллергия:** таомҳое, ки таркибашон маълум нест, барои онҳое, ки истисно доранд, тавсия дода намешаванд.

## 📈 Пешгӯии талабот (админ → 📈 Пешгӯӣ)

- Маълумот: танҳо фармоишҳои **DONE** ва пардохташуда (онлайн PAID / нақд CASH_COLLECTED). Бекоршуда ва пардохтнашуда дохил намешаванд. Рӯзҳо дар минтақаи Душанбе.
- Модели 1: миёнаи ҳаракаткунандаи 7-рӯза (MA-7). Модели 2 (MA-7 × омили рӯзи ҳафта) танҳо бо ≥28 рӯзи таърих.
- Бе leakage: рӯзи ҷорӣ ва маълумоти оянда дохил намешаванд.
- Арзёбӣ: walk-forward дар 14 рӯзи охир — **MAE** ва **WAPE**.
- Агар таърих кам бошад, ошкоро «маълумот нокифоя» нишон дода мешавад (рақами сохта нест).

## 🤝 Telegram-бот

1. Бо **@BotFather** бот созед → токенро ба `TELEGRAM_BOT_TOKEN` гузоред; номи бот (бе @) → `TELEGRAM_BOT_USERNAME`.
2. `TELEGRAM_WEBHOOK_SECRET` (16+ аломат, ҳарфу рақам) ва `TELEGRAM_ADMIN_IDS` (ID-ҳои **рақамии** Telegram, вергул бо ҷудо) танзим кунед. Админ бо **username** дастрас намешавад — танҳо ID.
3. Деплой → webhook-ро танзим кунед (як бор):
   ```bash
   TELEGRAM_BOT_TOKEN=... TELEGRAM_WEBHOOK_SECRET=... PUBLIC_URL=https://САЙТ-ШУМО npm run webhook
   ```
Фармонҳо: `/menu`, `/tavsiya [савол]` (AI/қоидаҳо), `/budget 50`, `/taste ...`, `/avoid ...`, `/prefs`, `/clear`, `/status`. Савол бо матни озод ҳам кор мекунад.
Пайвастшавӣ ба фармоиш: пас аз фармоиш дар сайт тугмаи **Telegram** → `/start o<id>_<токен>` (токени фармоиш).

Фармонҳои админ (танҳо барои ID-и рӯйхат, дар чати хусусӣ): `/pending`, `/approve <id>`, `/reject <id> [сабаб]`, `/order <id>`, `/setstatus <id> <СТАТУС>`.

## 🧭 Кор барои оянда (маълум)

- Нусхаи якум: JSON + як инстанс. Барои ресторани калон ва бисёр нусха — PostgreSQL.
- Контакт, Instagram/Telegram дар футер ҳоло ҷойгиранда (`+992 90 000 00 00`, `#`) — бо маълумоти воқеӣ иваз кунед.
- Номи ресторан ва адрес дар сайт (Рӯдакӣ 45) — санҷед.
- Сабаби рад ба мизоҷ нишон дода мешавад, аммо ҳанӯз огоҳии Telegram-и автоматӣ барои рад/тасдиқ нест.
