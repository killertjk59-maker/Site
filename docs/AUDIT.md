# Аудити OSHONA: v1.5.0 (7cc00c2) → v2.0.0

Ин ҳуҷҷат натиҷаҳои аудит, ислоҳҳо, натиҷаҳои тест ва мушкилоти боқимондаро ҷамъ мекунад.
Ҳамаи ёфтаҳо пеш аз тағйир бо **сервери воқеӣ** ва тестҳо исбот шуданд.

## 1. Усули кор

1. Кодро пурра хондем (`server.js`, `public/*`, конфигуратсия, README).
2. Бо `curl` ва сервери мавқеӣ заифиҳоро исбот кардем (ниже — ҷадвали ёфтаҳо).
3. **Пеш аз тағйирот** тестҳои характеризатсионӣ (ҷараёни ҷории фармоиш ва пардохт) ва тестҳои амниятиро навиштем.
4. Тағйирот ва ислоҳҳо.
5. Тестҳоро ҳам бар коди аслӣ (7cc00c2), ҳам бар коди нав иҷро кардем.

Нуқтаи бозгашт: тег `backup/pre-audit-7cc00c2` (бе шохаи нав).

## 4. Қарорҳои муҳим (бо далел)

- **Токени фармоиш** ба ҷои ҷустуҷӯ бо телефон. Пешниҳод: мизоҷ фармоишҳои худро дар дастгоҳи худ нигоҳ медорад. Ин маҳдудият аст (аз дастгоҳи дигар бо телефон дидан намешавад).
- **Пардохт — дастӣ** (ҳамон тавр). AI ҳеҷ гоҳ тасдиқ/рад намекунад (қоида дар `orders.js` ва тест).
- **Қоидаи ҳисоби тахфиф** (фоиз ба бутун) ҳамон аст, ки дар кӯҳна буд — рафтори пардохт тағйир наёфт.
- **Моделҳои OpenRouter**: `google/gemma-4-31b-it:free` (асосӣ), `nvidia/nemotron-3-super-120b-a12b:free`, `google/gemma-4-26b-a4b-it:free` (захиравӣ). `openai/gpt-oss-120b:free` ва `meta-llama/llama-3.3-70b-instruct:free` **истифода намешаванд**: `endpoints: []` (endpoint-и фаъол надоранд) — ин аз API-и расмӣ тафтиш шуд (2026-10-09).

## 6. Деплой (кӯтоҳ)

1. Variables: `JWT_SECRET` (32+), `ADMIN_PASSWORD` (10+), wallet-ҳо. Ихтиёрӣ: `OPENROUTER_API_KEY`, `TELEGRAM_*`, `CORS_ORIGINS`.
2. Volume: Mount Path `/app/data`.
3. Деплой → `GET /api/health` → `{"ok":true}`.
4. Telegram: `TELEGRAM_BOT_TOKEN=... TELEGRAM_WEBHOOK_SECRET=... PUBLIC_URL=https://... npm run webhook`.
5. Меню: тасдиқи таомҳо, ворид кардани таркиб ва вазн.
