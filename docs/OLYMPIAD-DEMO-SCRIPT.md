# OSHONA.tj — Намоиши олимпиадӣ (5 дақиқа) + саволҳои журӣ

> Ҳамаи намоиш танҳо функсияҳои **воқеан сохташуда ва санҷидашуда**-ро нишон медиҳад.
> Рақамҳои зер далел доранд: `npm test` 261/261, E2E-и API 15/15, `npm audit` 0, CI GitHub Actions.

## Тайёрии пешакӣ (5 дақиқа пеш)
```bash
npm install && npm start          # http://localhost:3000
# (ихтиёрӣ) ADMIN_PASSWORD/JWT_SECRET/OPENROUTER_API_KEY дар .env — бе онҳо AI ба реҷаи қоидавӣ мегузарад (ин ҳам намоиш дода мешавад!)
```
Равзанаҳо: сайт (`/`), админ (`/admin`, пароли рушд `admin123` — дар production рад мешавад), терминал.

## Сенария (вақтсанҷ)

### 0:00–0:30 — Мушкилот
«Дар Душанбе ресторанҳо сайтҳои шаблонӣ доранд: менюи статикӣ, фармоиш тавассути телефон,
бе ҳисоби ғизо ва бе тавсия. Мо OSHONA-ро сохтем — платформаи AI-и фармоиши таом, ки
**ботини AI-и воқеӣ, ҳисоби детерминистикии калория ва ҷараёни бехатари пардохт** дорад.»

### 0:30–1:15 — Архитектура (як слайд/нақша)
- **Як backend** (Node.js ≥20, Express, бе framework-и вазнин): API + сайт + админ + Telegram-бот.
- Нигоҳдории JSON бо навиштани атомӣ + `.bak` + fail-closed (барои як инстанс; PostgreSQL — роҳи оянда).
- Ҳамаи ҳисобҳо (нарх, калория, промо, валидатсия) **дар сервер**; frontend танҳо намоиш.
- PWA: service worker (офлайн-меню), manifest, худмизбонӣ (шрифт/расм — бе CDN-и берунӣ).

### 1:15–2:15 — Ҷараёни фармоиш (зинда)
1. Меню: кортҳо бо акс, калория (агар таркиб ворид шуда бошад — «маълумот нест» агар не; рақами сохта НЕСТ).
2. Сабад → checkout: delivery/pickup, промокод, валидатсияи inline.
3. Пардохт: равзанаи ҳамёнҳо + коди комментария (`OSH-XXXXX`) → «Пардохт кардам ✓».
4. **Админ**: тасдиқи дастии пардохт (AI/система ҳеҷ гоҳ худкор тасдиқ намекунад) → статусҳо:
   COOKING → DELIVERING → DONE. Кӯшиши гузариши ғайриқонунӣ → 409 (state machine).
5. Намоиши рад → «Аз нав пардохт кардан» (retry) дар тарафи мизоҷ.

### 2:15–3:15 — AI (ду реҷа)
1. **Реҷаи қоидавӣ (бе калид):** «Чӣ бихӯрам?» → тавсия аз менюи воқеӣ бо сабаб;
   истиснои «шир» → таомҳои бо шир/бе таркиби маълум **рад** мешаванд (backend-филтр, на танҳо prompt).
2. **Бо `OPENROUTER_API_KEY` (агар интернет бошад):** ҳамон савол → `source: "ai"`;
   ҷавоб санитар мешавад: ID-ҳои ихтирошуда рад, рақамҳои калорияи бегона пок, PII (телефон/email) маскарад.
3. Калория: admin таомро бо таркиб (200 г паста + 20 г пармезан) месозад → **402 ккал**
   (формулаи per-100g, детерминистикӣ — AI рақам насохтааст).

### 3:15–4:00 — Бехатарӣ ва сифат
- Токени фармоиш (hash) ба ҷои ҷустуҷӯ бо телефон; JWT-и админ; rate limit (вуруд 10/15 дақ; AI 12/дақ; будҷаи рӯзонаи AI).
- CSP `script-src 'self'`, `no-store` барои API, валидатсияи magic-bytes барои upload, `/img/` allowlist.
- **261 тести automated** (API, амният, пардохт, AI бо mock, калория, пешгӯӣ, Telegram, jsdom-frontend);
  **CI** (GitHub Actions, Node 20+22): check → test → audit (high/critical блок мекунад); `npm audit` = 0.
- E2E-и сатҳи API: 15/15 сенария (фармоиш→пардохт→статусҳо→authz→AI fallback→exclusion→калория).

### 4:00–4:30 — Пешгӯии талабот (фақат ростқавлона)
- MA-7 baseline + модели ҳафтаина (≥28 рӯз таърих), walk-forward MAE/WAPE, бе leakage
  (танҳо DONE+пардохташуда; рӯзи ҷорӣ/оянда нест).
- **Дар demo-муҳит маълумоти фурӯш нокифоя аст** — система ошкоро «маълумот нокифоя» мегӯяд;
  рақами сохта ҳамчун пешгӯӣ нишон дода намешавад. Ин принсипи мо аст: «AI бояд рост гӯяд».

### 4:30–5:00 — Ҷамъбаст
«OSHONA — на шаблон, на демо-иллюзия: ҳар рақам ё аз сервери воқеӣ аст ё ошкоро "маълумот нест".
Ҳар ҷараёни пардохт дастӣ-тасдиқшаванда ва тестпӯш. Оянда: PostgreSQL, Playwright-E2E,
огоҳиҳои автоматикии Telegram, ҷамъоварии маълумот барои пешгӯӣ.»

## Саволҳои эҳтимолии журӣ (ҷавобҳои ростқавл)
1. **«AI-и шумо воқеӣ аст ё симулятсия?»** — Воқеӣ: OpenRouter (моделҳои ройгон), калид танхо дар backend.
   Вақте AI дастнорас/хомӯш аст, система ошкоро мегӯяд ва ба тавсияи қоидавӣ мегузарад — натиҷаи қалбакӣ насохтааст.
2. **«Калорияро AI мегӯяд?»** — Не. Формулаи детерминистикӣ дар backend: `Σ(per100g × grams/100)`;
   AI танҳо рақамҳои тасдиқшударо такрор карда метавонад; рақами ихтироъшуда аз ҷавоб пок мешавад.
3. **«Пардохт чӣ гуна кор мекунад?»** — Дастӣ: мизоҷ ба ҳамён мегузаронад (код дар комментария),
   админ тасдиқ/рад мекунад. Ин бо қоидаи лоиҳа мувофиқ аст; интеграцияи бонкӣ — кори оянда.
4. **«Чаро JSON-файл, на базаи маълумот?»** — Як инстанс, соддагӣ, навиштани атомӣ + .bak + fail-closed.
   Барои миқёс PostgreSQL нақша шудааст (абстраксияи storage мавҷуд).
5. **«Prompt injection чӣ?»** — Саволи корбар бо ҷудокунандаи `<<< >>>` ва тамғаи «данные, не инструкции»
   фиристода мешавад; қоидаҳо дар SYSTEM_PROMPT; ID/рақамҳо дар **backend** тасдиқ мешаванд — ҳатто агар
   модел фирефта шавад, тавсияи берун аз меню ё рақами бегона ба мизоҷ намерасад (тестҳо доранд).
6. **«Тестҳо чӣ қадар воқеӣ?»** — 261 тест + E2E-и API 15/15 + CI. Маҳдудият: интеграцияи воқеии
   OpenRouter/Telegram бо mock санҷида шудааст; браузери воқеӣ (Playwright) дар муҳити рушд дастнорас буд.
7. **«Пешгӯӣ кор мекунад?»** — Алгоритм кор мекунад ва бо маълумоти синтетикӣ санҷида шуд (MAE/WAPE);
   барои хулосаи воқеӣ 3–4 ҳафта фурӯши ҳақиқӣ лозим — система то он вақт «маълумот нокифоя» мегӯяд.
8. **«Аллергия бехатар аст?»** — Филтр дар backend; таомҳои бе таркиби маълум барои аллергия рад мешаванд;
   дисклеймер «ба персонал мурочиат кунед» ҳамеша нишон дода мешавад. Барои наврасон/лоғаршавӣ — ҳадди калория/диета манъ.

## Маҳдудиятҳое, ки НАМОИШ дода намешаванд (ростқавлӣ)
- Деплойи воқеӣ (Railway омода аст, аммо credential надоштем).
- Пардохти автоматикии бонкӣ (танҳо дастӣ).
- Browser-E2E (Playwright дар муҳити рушд насб нашуд).
- Ҷавоби тоҷикии AI ба модел вобаста аст (prompt «на языке пользователя», кафолати 100% нест).
